# FarmFit frontend

Next.js + TypeScript + Tailwind + MapLibre GL + Turf.js. See the repository-root README for setup, architecture and the optimization model.

- `npm run dev` / `npm run build && npm start`
- `npm test` runs the geometry and layout tests (vitest)
- `NEXT_PUBLIC_API_URL` points at the FastAPI service (default http://127.0.0.1:8000)
